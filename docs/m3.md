# M3 — two intersections, evolution tape, sustained PK

M0/M1/M2 still own one intersection. M3 does not change that law and does
not load into `m0_smoke.aura`. The new world is `soft/evolve/grid.aura`:
a corridor of two nodes. Each node has its own phase, green age, and NS/EW
queues. One LCG feeds both. Each tick arrives on both nodes (four draws),
then both choose, then both serve up to 2. The score is one integer:

`throughput - queue_pen - stop_pen`

across both nodes. Tick 24 still does `(set! *g-stop-w* 3)` and prints
`MUTATE`. Earlier stop penalty is not retconned.

A shared policy passes the same chooser to both nodes. A per-node policy
passes a different chooser to each node. The per-node line in the smoke is
host-sequential on purpose. The shared agg-vs-calm race is the fiber race.

## Tape

Soft prints `ETAPE op=... tick=... mid=... score=... reason=...` for
`SWAP`, `HEAL`, `MUTATE`, `RACE`, `KEEP`, and `DROP`. That log is
append-only in emit order. `scripts/collect_tape.py` copies it to
`out/tape_m3.md` or `out/tape_pk.md`. `bash scripts/replay_tape.sh`
pretty-prints the newest `out/tape_*.md`. It does not rewind the world.

Snapshot `TAPE tick=` lines are still the grid state every 10 ticks of a
kept replay. They are not the decision log.

## Measured grid (seed 20261005, horizon 60)

`bash scripts/smoke_m3.sh`

| line | value |
|------|--------|
| shared agg (mid 1) | `-1167` KEEP `higher-score-stamp` |
| shared calm (mid 2) | `-1837` DROP `lower-score-rollback` |
| per-node n0=agg n1=chase (mid 3) | `-1165` KEEP `per-node-higher` |
| live | thru `236` qpen `1148` spen `253` score `-1165` |
| end queues | n0 `1/5` n1 `12/11` (NS/EW) |
| `WORLD` | `line=fiber_live backend=2 joins=2/2` |
| end | `EVOLVE_M3_OK` |

`backend=2` is the CLI thread fallback, same as M1. Joins matched, and the
scores match a host-sequential probe, so the stamp is `fiber_live`. If a
future binary misses a join, the same thunks run on the host and the line
is `host-sequential`. The smoke must not print `fiber_live` unless
`joins` left and right are equal and the backend is > 0.

`SWAP` / `HEAL` on `ev:choose` happen before the grid race (chase body,
then an ugly pair that heals back). They are on the tape. They do not
reset grid queues.

## PK

`bash scripts/burn_pk.sh`

- `EVOLVE_PK_ROUNDS` default 4 (falls back to `EVOLVE_BURN_ROUNDS`).
- `EVOLVE_HORIZON` default 24.
- `EVOLVE_PROPOSE=0` uses `soft/evolve/fixtures/pk/{1,2,3,4}.lambda`.
- `EVOLVE_PROPOSE=1` (default) calls MiniMax once per round when
  `~/.config/aura-build/minimax_api_key` is non-empty, else the same
  fixtures. HTTP stays in `scripts/propose_minimax.py`
  (`https://api.minimax.cn/v1` only).
- Scoreboard: `out/pk_scoreboard.md`. The `WORLD` line in that file is
  copied from Soft. The script does not invent `fiber_live`.
- Tape: `out/tape_pk.md`.

Each round installs the lambda as a **shared** policy and races it against
the current main on the corridor. KEEP only when `trial > base`. A tie
DROPs and `heal!`s.

Fixture contract (horizon 24, `EVOLVE_PROPOSE=0`), pinned in `pk.aura`:

| round | body | race | stamp |
|-------|------|------|--------|
| baseline | agg | `-276` | |
| 1 | chase (`other > own`) | base `-276` trial `-237` | KEEP |
| 2 | always switch | base `-237` trial `-291` | DROP |
| 3 | always hold | base `-237` trial `-731` | DROP |
| 4 | age≥8 or chase | base `-237` trial `-237` | DROP (tie) |

`WORLD line=fiber_live backend=2 joins=8/8` (four races, two fibers each).
`MAIN score=-237`. `EVOLVE_PK_OK`.

Live rounds are not score-pinned. Any honest tag
(`propose_keep`, `propose_drop`, `propose_heal`, `propose_reject`) can
finish `EVOLVE_PK_OK`. The fixture script additionally requires a KEEP and
a DROP. No key is not a failure: the script uses fixtures.

## Run

```bash
bash scripts/smoke_m3.sh
EVOLVE_PROPOSE=0 bash scripts/burn_pk.sh
bash scripts/replay_tape.sh
bash scripts/smoke.sh
```

## 中文

M3 把世界扩成两条路口的走廊。每个节点自己的相位、绿灯年龄、南北/东西
队列。分数是两条加总：吞吐 − 排队 − 停车。策略可以两条共用，也可以
一节点一套。种子 `20261005`、60 拍：共用 agg -1167 胜过共用 calm
-1837；节点 0 agg、节点 1 chase 得到 -1165，再留下。

`out/tape_*.md` 打出来，不假装能倒带。
PK 默认四轮、地平线 24。离线 fixture：追逐体 KEEP（-237），一直切换
DROP，一直不切换 DROP，和平局也 DROP。记分牌在 `out/pk_scoreboard.md`。
这次是 `fiber_live backend=2 joins=8/8`。对不上 join 就印
`host-sequential`。
