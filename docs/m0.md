# M0 smoke sequence

Deterministic Soft script `soft/evolve/m0_smoke.aura`. Seed `20261005`,
horizon 60. Dialect string: `city-light-factory-m0`.

NS / EW is one intersection. Read it as a city crossing or as two factory
lines that share one green. The numbers do not change between those readings.

## Law

1. `(ev:reset! seed)` sets the LCG to `seed`, phase to NS green (`0`),
   green age `0`, queues `0`, counters `0`, `*stop-w*` `1`.
2. LCG step: `(modulo (+ (* rng 75) 74) 65537)`.
3. Each tick, NS arrivals are `(modulo (ev:rng!) 3)`, then EW the same.
   A positive arrival on red adds to the queue, to `*stops*`, and to
   `*stop-pen*` by `*stop-w*` times the count. Green arrivals only join
   the queue.
4. The active body sees `(age own other)` and returns `1` (switch) or `0`
   (hold). A switch flips phase and zeros green age before service.
5. Green serves `min(queue, 2)`. That count is throughput.
6. Remaining `q-ns + q-ew` is added to `*queue-pen*`. Green age then
   increments. Tick increments.
7. When tick becomes 24, `(set! *stop-w* 3)` and the script prints
   `MUTATE tick=24 stop-w=3 slot=<body>`. Earlier stop penalty is kept.
8. Score is `(- throughput (+ queue-pen stop-pen))`.

## Bodies

| mid | name | rule |
|-----|------|------|
| 1 | `strat-agg` | switch if age ≥ 4, or if age ≥ 2 and the other queue is longer |
| 2 | `strat-calm` | switch if age ≥ 12, or if age ≥ 8 and own queue is 0 while the other is not |

`strat-agg` is the short-green / throughput body. `strat-calm` is the
long-green / fewer-stops body. Both are plain Soft procedures. M0 does not
`set-code` them and does not `hot-strategy:register!` them.

## Race

Host-sequential. `ev:run!` resets to `*seed*` and plays 60 ticks. Agg runs,
then calm runs. No `fiber:spawn`. `joins=0/2`.

The greater score wins. A tie would KEEP agg (`tie-keep-agg-stamp`). This
seed is not a tie.

The winner is replayed with the tape flag on, so the live world ends as
the kept line. The loser is not replayed into the main slot. That is the
rollback.
