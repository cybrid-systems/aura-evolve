# M2 — propose, gate, KEEP / DROP

Soft does not speak HTTP. `scripts/propose_minimax.py` reads
`~/.config/aura-build/minimax.env` (`MINIMAX_API_KEY_FILE`,
`MINIMAX_MODEL`, default `MiniMax-M3`). The default base URL is
`https://api.minimax.cn/v1`. If the env file says `api.minimaxi.com`, the
script rewrites it to `api.minimax.cn` and prints `PROPOSE_BASE`. It never
calls `api.minimaxi.com`. The key file is not in the repo and is never
printed.

The script writes one line `(lambda (age own other) ...)`. Soft gates that
string, swaps it into `ev:choose`, and races it against `ev:shadow` (the
current main) on the same seed.

## Gate

Rejected before swap: not a `(lambda (age own other) ...)`, or the text
contains `set!`, `vector-set!`, `display`, `mutate`, `eval`, `load`,
`shell`, `http`, `ev:reset`, `ev:tick`, `ev:race`, or `fiber:`.

Swapped, then healed, when the probe `(ev:choose 4 1 2)` is not 0 or 1
(`propose_heal`).

## KEEP rule

`KEEP` only when `trial > base`. Equal scores `DROP` and `heal!` the
pre-trial snapshot (`lower-score-rollback`). The kept string becomes
`*main-body*` and the next round's shadow.

Worldline stamp uses the same rule as M1: `fiber_live` only when every
race in the process spawned two distinct fibers and both joins returned
numbers. Fixture smoke races twice (the hold body and the chase body), so
a live backend prints `joins=4/4`.

## Burn

`bash scripts/burn.sh`

- `EVOLVE_BURN_ROUNDS` default 3, `EVOLVE_HORIZON` default 24.
- `EVOLVE_PROPOSE=0` uses `soft/evolve/fixtures/burn/{1,2,3}.lambda`.
- `EVOLVE_PROPOSE=1` (default) calls MiniMax once per round when
  `~/.config/aura-build/minimax_api_key` is non-empty, else the same fixtures.

## Live

`bash scripts/smoke.sh` calls MiniMax once when the key file exists, then
`m2_live.aura`. Any honest tag (`propose_keep`, `propose_drop`,
`propose_heal`, `propose_reject`) prints `EVOLVE_M2_PROPOSE_LIVE_OK`.
No key prints `EVOLVE_M2_PROPOSE_LIVE_SKIP` and is success. A failed HTTP
call, or a Soft error, is `EVOLVE_M2_PROPOSE_LIVE_FAIL`.

One measured live lambda lost to agg (`RACE base=-764 trial=-820`), so
the stamp was `DROP` plus `HEAL`, and the line was
`fiber_live backend=2 joins=2/2`. That is a successful gate, not a keep.
