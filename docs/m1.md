# M1 — hot-strategy and an honest worldline

`soft/evolve/m1_smoke.aura`. Seed `20261005`. M0 is unchanged: it does not
load this path and still prints `WORLD line=host-sequential joins=0/2`.

## What M1 guarantees

1. `ev:choose` is a real `std/hot-strategy` slot. Seed is `set-code` plus
   `hot-strategy:register!`. A later body goes in with `hot-strategy:swap!`.
   `hot-strategy:heal!` restores the pre-swap snapshot. This is not a
   renamed `set!`.
2. The slot can change **mid-run**. Ten ticks run on the seed body
   (`strat-agg` shape). A `set!` body is gate-rejected and the tick stays
   10. A chase body is swapped in (`SWAP name=ev:choose tick=10`). Five
   more ticks run on that body (`tick=15`). An ugly body that returns a
   pair fails the 0/1 probe, `heal!` runs, and tick is still 15. Queues
   are not retconned by the swap.
3. Heal restores the last good snapshot, which is the chase body, not the
   original seed. `(ev:choose 5 5 1)` is 0 after that heal (agg would
   return 1).
4. The dual race is still `strat-agg` vs `strat-calm` on the same seed,
   separate from the hot-slot demo. `KEEP` / `DROP` use the greater score.
   Tie would keep agg. This seed is not a tie.
5. `fiber_live` is printed only when that race spawned two distinct
   positive fiber ids and both `fiber:join`s returned a number, and
   `fiber:spawn-backend` is > 0. Otherwise the same two thunks run on the
   host and the line is `host-sequential`. A missed join is not labeled
   `fiber_live`.

## Measured on this tip

`bash scripts/smoke_m1.sh` against `/workspace/aura-grok/build/aura`:

| line | value |
|------|--------|
| `SWAP` | `name=ev:choose tick=10 reason=mid-swap` |
| `HEAL` | `name=ev:choose tick=15 reason=probe` |
| `RACE` | `agg=-764 calm=-1086` |
| `WORLD` | `line=fiber_live backend=2 joins=2/2` |
| `KEEP` | `mid=1 reason=higher-score-stamp` |
| `DROP` | `mid=2 reason=lower-score-rollback` |
| end | `EVOLVE_M1_OK` |

`backend=2` is the CLI thread fallback (`fiber:spawn-backend`), not the
serve-async scheduler (`backend=1`). Joins landed and the scores match the
host-sequential M0 tape, so the stamp is `fiber_live`. If a future binary
returns `#f` from spawn or join, this smoke still passes with
`host-sequential` and must not say `fiber_live`.

`MUTATE tick=24 stop-w=3` still comes from the world tick, once per
worldline pass (both forks and the kept replay).

## 中文

M1 在第 10 拍 `hot-strategy:swap!` 换灯控策略，第 15 拍用
`hot-strategy:heal!` 拉回上一份好快照。tick 不被 swap 清掉。
`strat-agg` 对 `strat-calm` 的双世界线：这次二进制上两条 fiber 都
join 成功，所以印 `fiber_live backend=2 joins=2/2`。backend 2 是
CLI 线程回退，不是 serve-async。没 join 就不印 `fiber_live`。
M0 仍然是 `host-sequential joins=0/2`。
